Questions? Answers.

Everything people usually ask before making the switch to Fluxxbank.

Fluxxbank provides digital banking services with instant transfers, multi-currency accounts and card controls.
Transfers between Fluxxbank members are instant and free. External payments are processed according to the selected rail.
New accounts start as Pending. An administrator reviews the application and generates a one-time 6-digit code (valid 15 minutes, usable once). You enter it after signing in — the code is verified server-side and never shown in the app or sent by email.
Only you — and authorised administrators. Every table is protected by Row Level Security keyed to your account ID, so one customer can never read or modify another customer's profile, balance, transactions, cards, documents or tickets.
A static frontend (HTML/CSS/JS) backed by Supabase: Postgres with RLS for storage, Auth for sessions, Storage for support attachments, and SECURITY DEFINER database functions for all financial operations.
